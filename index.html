PROJECT / 001Mar 2026 – Present

Integrated Hotel Management
& Channel System

View on GitHub →
JavaMongoDBDocument DBREST APIMulti-Channel Sync
Situation

Hotel operators managing bookings across multiple OTA platforms face critical data silos and schema-rigid SQL systems that can't adapt to dynamic room types — causing double-bookings and lost revenue.

Task

Design a high-availability, schema-flexible management core capable of handling diverse room configurations, multi-rate-plan guest profiles, and bi-directional synchronization across channels without downtime.

Action

Architected in Java for concurrency strength. Selected MongoDB's document model to store nested booking objects — room attributes, guest history, and channel metadata in a single queryable document, eliminating costly JOIN operations.

Impact

Achieved zero-schema-migration overhead for new room types. Real-time booking logs enable instant conflict detection, effectively eliminating double-booking risk. Architecture supports horizontal scaling for new OTA channels.

PROJECT / 002Aug 2025 – Present

IoT Home Automation
System

View on GitHub →
ESP32MQTTHTTPWi-FiWeb DashboardC/C++
Situation

Consumer smart home products are cloud-locked and privacy-invasive. Homeowners need a custom, self-hosted automation layer without expensive subscriptions or third-party dependencies.

Task

Build a complete hardware-to-dashboard pipeline using embedded microcontrollers — covering appliance control, remote monitoring, and energy efficiency from a responsive browser interface.

Action

Selected ESP32 for its dual-core architecture and native Wi-Fi stack. Implemented both HTTP REST endpoints and MQTT pub/sub, providing redundant paths. Engineered deep-sleep wake cycles to cut idle power draw dramatically.

Impact

Deep-sleep achieved measurable standby power reduction across sensor nodes. MQTT delivers sub-100ms command latency. Full remote access via browser — no proprietary app required.

PROJECT / 003Dec 2025 – Present

CampusEase — Smart
Campus Management App

View on GitHub →
FlutterFirebaseDartResponsive UIReal-time DB
Situation

Campus administration relies on fragmented paper-based processes. Students and faculty need a unified mobile-first platform that centralizes operations — attendance, notices, timetables — into one coherent experience.

Task

Develop a cross-platform application serving both mobile and desktop with a real-time backend capable of pushing instant updates — announcements, schedule changes, attendance — to all users simultaneously.

Action

Chose Flutter's single codebase to target mobile and desktop with shared business logic. Leveraged Firebase Realtime Database for push-driven data, eliminating polling. Built responsive layout breakpoints for 5" phone to 24" desktop.

Impact

One codebase covers Android, iOS, and desktop — cutting development time vs native by over 60%. Firebase sync ensures zero-latency notification delivery for critical announcements. No separate mobile and web teams needed.
