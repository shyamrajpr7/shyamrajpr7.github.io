PROJECT / 001Mar 2026 - Present

Integrated Hotel Management
& Channel System

View on GitHub →
JavaSpring BootMongoDBREST APIOTA Integration
Situation

Hotel operators managing bookings across multiple OTA platforms face critical data silos and schema-rigid SQL systems that can't adapt to dynamic room types -- causing double-bookings and lost revenue.

Task

Design a high-availability, schema-flexible management core handling diverse room configurations, multi-rate guest profiles, and bi-directional channel sync across platforms like Booking.com and Expedia-style OTAs.

Action

Architected in Java with Spring Boot. Used MongoDB's document model to store nested booking objects in one queryable document, eliminating costly JOINs, and engineered RESTful CRUD endpoints for reservations and inventory.

Impact

Achieved zero-schema-migration overhead for new room types. Real-time sync minimizes double-booking risk, with interoperable endpoints ready for third-party integrations.

PROJECT / 003Aug 2025 - Present

Home Automation
IoT System

View on GitHub →
ESP32MQTTHTTPWi-FiC++Deep-Sleep
Situation

Consumer smart-home products are cloud-locked and privacy-invasive. Homeowners need a custom, self-hosted automation layer without subscriptions or third-party dependencies.

Task

Build a complete hardware-to-dashboard pipeline on a microcontroller, covering appliance control, telemetry, and energy efficiency from a real-time browser interface.

Action

Selected ESP32 for dual-core Wi-Fi capability. Implemented dual-protocol communication -- HTTP REST for commands, MQTT pub/sub for telemetry -- and engineered deep-sleep wake cycles for sensor nodes.

Impact

Achieved sub-100ms switching latency with redundant communication paths. Deep-sleep optimization extended battery life significantly for wireless sensor nodes.
